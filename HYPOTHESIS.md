# Pre-Registered Evaluation Protocol & Hypothesis (`disRated`)

## 1. Scope & Dataset Provenance
- **Benchmark:** VHD11K (10,000 images; binary `decision` label generated by 3-VLM debate judge).
- **Framing:** Selective classification and compute-triage evaluation measuring agreement with the benchmark's debate judge. No claims are made regarding explicit-content completeness or objective ground-truth safety beyond judge agreement.
- **Active Splits:** `splits.v2.json` (`sha256: 07b1776d1d8ec1949e799859fe321e993361d6998040534601f81e4b0e3b09f2`), 8,000 train / 1,000 val / 1,000 test, grouped over 8,449 connected components (`embeddings/components.json`, `sha256: d67fd10c8d50287fb3016176064a4bf476e02104e614eb5cb51864851d1870f3`).

## 2. Experimental Arms
All arms are evaluated on the exact same validation ($N = 1,000$) and held-out test ($N = 1,000$) partitions:
1. **`probe-only` (Tier 0 Baseline):** $L_2$-regularised logistic regression ($C = 1.0$, tuned on `val`) fit on frozen `openai/clip-vit-base-patch16` `train` features. Hard decisions taken at $p \ge 0.50$ ($\text{logit}(p) > 0$).
2. **`vlm-only` (Tier 2 Baseline):** Zero-shot Vision-Language Model evaluated across 100% of split images.
3. **`cascade` (Proposed):** One-knob uncertainty routing around the probe decision boundary. For a scalar cutoff $c > 0$ on $\vert{}\text{logit}(p_{\text{probe}})\vert{}$:
   - If $\vert{}\text{logit}(p_{\text{probe}})\vert{} \ge c$: emit `probe-only` hard decision ($\text{logit} > 0$).
   - If $\vert{}\text{logit}(p_{\text{probe}})\vert{} < c$: escalate image to `vlm-only` and emit the VLM's hard decision.
4. **`random-control` (Gating Control):** Escalates the exact same number of images $N_{\text{esc}}$ as `cascade` on the evaluated split, chosen uniformly at random (seeded deterministically at `seed = 0`), while routing the remaining $N - N_{\text{esc}}$ images to `probe-only`.

## 3. Primary Metric & Statistical Testing
- **Primary Metric:** Binary `macro_f1` against `decision`, defined as $\frac{1}{2}(F_{1,\text{harmful}} + F_{1,\text{safe}})$.
- **Secondary Metrics:** Overall accuracy, in-band accuracy, resolved accuracy, realised escalation rate, VLM refusal rate, and per-source (`concept` vs. `sdxl`) `macro_f1`.
- **Uncertainty Estimation:** 95% confidence intervals computed via paired non-parametric bootstrap ($B = 10,000$ resamples of split indices with replacement, `seed = 0`).

## 4. Threshold Selection Rule & Validation Gate
Threshold values are **not** fixed in advance of VLM validation runs. Instead, the selection rule is frozen now and executed once `vlm-only` validation predictions exist, prior to touching `test`:

1. **Candidate Cutoffs:** Define candidate cutoffs $c_k = \text{Quantile}(\vert{}\text{logit}(p_{\text{val}})\vert{}, k)$ for $k \in \{0.05, 0.10, 0.15, 0.20, 0.25, 0.30\}$.
2. **Pre-Test Validation Gate (In-Band Superiority):** On `val`, at the selected cutoff $c_k$, the VLM's accuracy on the escalated band ($\vert{}\text{logit}(p_{\text{val}})\vert{} < c_k$) must exceed the probe's accuracy on the exact same subset. If the VLM fails to beat the probe inside the uncertain band on `val`, escalation adds no value; test evaluation will still be recorded for completeness, but the hypothesis is marked falsified at the gate.
3. **Operating Point Selection:** Among candidate values $k \in \{0.05, \dots, 0.30\}$ passing the Validation Gate:
   - Select the smallest $k$ whose `val` cascade `macro_f1` is within $0.030$ of `vlm-only` ($\text{Macro-}F_1(\text{cascade}) \ge \text{Macro-}F_1(\text{vlm-only}) - 0.030$) **and** strictly exceeds `probe-only`.
   - Fallback: If no $k \le 0.30$ reaches within $0.030$ of `vlm-only` (or if `vlm-only` underperforms `probe-only`), select the $k \in \{0.05, \dots, 0.30\}$ that maximises `val` cascade `macro_f1`.
4. **Transfer to Test:** Lock the scalar logit threshold $c^* = c_{k^*}$ from `val` and apply $c^*$ unchanged to `test`. The test escalation rate $k_{\text{test}}$ is an empirical outcome, not a quantile recomputed on `test`.

## 5. Pass / Falsification Criteria (Held-Out Test Split)
The hypothesis passes on `test` if and only if **all five** conditions hold at the locked cutoff $c^*$:
1. **Budget Cap:** Realised test escalation rate $k_{\text{test}} \le 0.300$.
2. **Superiority over Probe-Only:** Paired difference $\Delta_{\text{probe}} = \text{Macro-}F_1(\text{cascade}) - \text{Macro-}F_1(\text{probe-only}) > 0$, with the 95% paired bootstrap CI lower bound $> 0$.
3. **Non-Inferiority to VLM-Only:** Paired difference $\Delta_{\text{vlm}} = \text{Macro-}F_1(\text{cascade}) - \text{Macro-}F_1(\text{vlm-only})$ has a 95% paired bootstrap CI lower bound $\ge -0.030$.
4. **Superiority over Random Routing:** Paired difference $\Delta_{\text{rand}} = \text{Macro-}F_1(\text{cascade}) - \text{Macro-}F_1(\text{random-control}) > 0$, with the 95% paired bootstrap CI lower bound $> 0$.
5. **In-Band Gain:** On the escalated test subset ($\vert{}\text{logit}(p_{\text{test}})\vert{} < c^*$), VLM accuracy exceeds probe accuracy.

If any criterion fails, the cascade hypothesis is falsified and reported directly as a negative or bounded empirical finding alongside the exact paired effect sizes.
